# پنل مالی شخصی

وب‌اپ (PWA) مدیریت مالی شخصی که روی GitHub Pages اجرا می‌شه و روی لپ‌تاپ و موبایل مثل یک اپ نصب می‌شه. طراحی سیاه و سفید با سبک Liquid Glass و حالت روشن/تیره.

## امکانات
- **هزینه** (قرمز)، **درآمد** (سبز)، **طلب** (زرد)، **بدهی** (سرخ تیره) — همه به تومان با علت و تاریخ شمسی
- تیک **طلب** ← خودکار به درآمدها اضافه می‌شه؛ تیک **بدهی** ← خودکار به هزینه‌ها
- **خریدهای آینده** با قیمت دلاری و تبدیل لحظه‌ای به تومان؛ تیک «خریدم» ← به هزینه‌ها
- **بازار**: دلار، یورو، پوند، درهم، طلای ۱۸ و ۲۴ عیار، شاخص بورس — با نمودار قیمت (۲۴ ساعت تا یک سال)
- **تقویم شمسی** با تاریخ امروز در بالای صفحه، تعطیلات رسمی ثابت، و تراکنش‌های هر روز
- خلاصه ماهانه، نمودار ۶ ماه اخیر، دسته‌بندی هزینه‌ها، جستجو
- همگام‌سازی بین دستگاه‌ها با **GitHub Gist خصوصی**
- قفل با رمز ۴ تا ۶ رقمی، خروجی و ورود JSON، کار آفلاین

## راه‌اندازی روی GitHub Pages
1. در ریپو: **Settings → Pages**
2. در **Build and deployment**، Source را روی **Deploy from a branch** و Branch را روی **main** و پوشه **/ (root)** بگذار و Save کن
3. بعد از یکی دو دقیقه آدرس پنل نمایش داده می‌شه: `https://<username>.github.io/<repo>/`

## نصب روی دستگاه‌ها
- **آیفون (Safari):** دکمه Share ← Add to Home Screen
- **اندروید (Chrome):** منوی ⋮ ← Install app / Add to Home screen
- **لپ‌تاپ (Chrome/Edge):** آیکون نصب در نوار آدرس

## همگام‌سازی لپ‌تاپ و موبایل
1. گیت‌هاب ← Settings ← Developer settings ← Personal access tokens ← **Fine-grained tokens** ← Generate new token
2. در **Account permissions** فقط **Gists: Read and write** را فعال کن
3. توکن را در تنظیمات پنل وارد کن و «اتصال» بزن — اولین بار یک Gist خصوصی ساخته می‌شه
4. روی دستگاه دوم همان توکن را وارد کن؛ Gist قبلی خودکار پیدا می‌شه

داده‌ها هر بار که چیزی ثبت می‌کنی و هر یک دقیقه (وقتی پنل بازه) همگام می‌شن. اگر روی دو دستگاه همزمان تغییر بدی، نسخه‌ای که دیرتر ویرایش شده می‌مونه.

> توکن فقط روی همان دستگاه ذخیره می‌شه و داخل ریپو یا Gist نمی‌ره.

## منبع قیمت‌ها
- **بدون کلید:** قیمت دلار از تتر نوبیتکس، طلا از PAXG نوبیتکس، و یورو/پوند/درهم از نرخ جهانی محاسبه می‌شه (تقریبی). شاخص بورس در این حالت در دسترس نیست.
- **با کلید BrsApi.ir (رایگان):** قیمت دقیق بازار آزاد ارز و طلا و شاخص کل بورس. کلید را در تنظیمات وارد کن.

قیمت‌ها هر ۵ دقیقه به‌روز می‌شن و پنل تاریخچه‌شان را برای نمودار ذخیره می‌کنه.

## ساختار فایل‌ها
```
index.html            پوسته برنامه
styles.css            طراحی (Liquid Glass، تم روشن/تیره)
sw.js                 سرویس ورکر (آفلاین)
manifest.webmanifest  تنظیمات نصب PWA
js/app.js             صفحه‌ها و رابط کاربری
js/store.js           ذخیره داده و ادغام
js/sync.js            همگام‌سازی با Gist
js/prices.js          قیمت‌ها و تاریخچه
js/charts.js          نمودارها
js/jalali.js          تقویم شمسی
js/format.js          قالب‌بندی اعداد
```
